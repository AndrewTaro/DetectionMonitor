# Detection Monitor
This mod indicates the detected players.

For a caster observing a training room it also shows, beside each ship's icon:

- **Detection type**: an icon when the ship is seen by something other than a ship's eyes (aircraft, radar, hydro, submarine gear).
- **Shot penalty**: the seconds left of the extra visibility a ship gets after firing its main battery.

AutoSpy, who no longer plays World of Warships, developed the original concept of this mod.

# Install
1. Download a zip.
2. Unzip the archive and you should get `gui` and `PnFMods` folders, and `PnFModsLoader.py`.
3. Move them to `(wows)/bin/(latest_number)/res_mods/`. So the path will look like `res_mods/PnFModsLoader.py`, etc.
4. Done!
